# Support

- **Docs**: https://agentmove.zalize.com
- **Questions / ideas**: GitHub Discussions or issues at
  https://github.com/wookat/agentmove/issues
- **Bugs**: open an issue with the output of `agentmove doctor` (it contains no
  secrets — values are inventoried, not printed) and the exact command you ran.
- **Security problems**: see [SECURITY.md](SECURITY.md).
