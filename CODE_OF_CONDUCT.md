# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We are committed to a harassment-free experience for everyone. Examples of
unacceptable behavior include trolling, insulting comments, personal or
political attacks, and publishing others' private information.

Enforcement: report violations to the maintainers via GitHub
(https://github.com/wookat/agentmove/issues for non-sensitive matters, or the
security contact in SECURITY.md for sensitive reports). Maintainers may remove
comments, reject contributions, or ban contributors for behavior they deem
inappropriate.
